1. What is the difference between null and undefined?  
-> null is a primitive value which means empty, type of null is object. it is set intentionally. whereas undefined means no value is assigned yet. it is set automatically.

2. What is the use of the map() function in JavaScript? How is it different from forEach()?  
-> map() is used to perform operation on every element of an array and return a modified array. foreach doesn't return a new array, it is used just to do something with each element.

3. What is the difference between == and ===?   
-> == checks if the values are equal, it doesn't check type but it does type coercion. === checks both value and type, if both are equal it returns true otherwise false. 

4. What is the significance of async/await in fetching API data?   
-> async/await makes asynchronous code work synchronously. it helps avoid long .then chains which makes code easy to read and manage.

5. Explain the concept of Scope in JavaScript (Global, Function, Block).   
-> scope determines where a variable or function is accessible. global scope means it is accessible everywhere. function scope means it is accessible only inside the function. block scope means it is accessible only inside the block it is declared in.
